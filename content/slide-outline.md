## SL02 色彩為什麼重要？

- 學習目標：說明色彩如何參與資訊組織與情緒聯想
- 視覺層級可以引導閱讀順序，對比協助區分資訊。（M06 / 核心定義；S007）
- 色彩與注意及評價的關聯受情境影響。（M04 / 核心定義；S004）
- 範例：同一張活動卡片使用不同強調色，觀察自己先注意哪裡；不假定所有人反應相同。
- 視覺：兩張相同文字的原創卡片
- 互動：design-compare

## SL03 我們如何感知色彩？

- 學習目標：理解相同色碼可能有不同感知效果
- 相同灰色在不同背景上可能呈現不同的明暗感受。（M05 / 核心定義；S006）
- 相同 HSL 明度不保證相同感知亮度。（M05 / 基礎理論；S003）
- 範例：比較深淺背景上的灰色方塊；不講授尚缺證據的生理視覺機制。
- 視覺：雙背景示意
- 互動：contrast-illusion

## SL04 色彩三要素 HSL

- 學習目標：分別辨識色相、飽和度、明度
- Hue 用角度表示；Saturation 和 Lightness 用百分比表示。（M01 / 核心定義；S003）
- 飽和度為零時為灰階，明度兩端分別為黑與白。（M01 / 基礎理論；S003）
- 範例：固定 H=0，依次調整 S 與 L。
- 視覺：色塊與三個滑桿
- 互動：hsl

## SL05 RGB 與 CMYK

- 學習目標：區分螢幕加法與印刷減法混色
- RGB 使用紅綠藍光；CMYK 以印刷油墨減法混色。（M02 / 核心定義；S002）
- RGB 全強度合成白；CSS 可用 HEX、RGB、HSL 表色。（M02 / 基礎理論；S002, S003）
- 印刷受設備與色彩管理影響，不能承諾精準轉換。（M02 / 適用限制；S002）
- 範例：RGB 三通道設成 255，觀察白色。
- 視覺：三通道混色與印刷示意
- 互動：rgb

## SL06 認識兩種色輪

- 學習目標：辨識 RYB 與 HSL 的對向色差異
- 傳統 RYB 教學色輪的紅與綠為對向色。（M03 / 核心定義；S001）
- 數位 HSL 0° 為紅，180° 為青，360° 回到紅。（M03 / 基礎理論；S003）
- 範例：切換兩種色輪，比較紅色的對向位置。
- 視覺：並列標示 RYB 與 HSL
- 互動：wheel

## SL07 六種配色方法

- 學習目標：運用數位 HSL 規則建立候選色票
- 工具設定：單色固定 H 改 S/L；類似 H±30°；互補 H+180°；分裂互補 H+150°、H+210°；三色 H+120°、H+240°；Square H+90°、H+180°、H+270°。角度取模 360。（M03 / 基礎理論；project_rule）
- 色輪角度不是感知均勻距離，色相對比不保證可讀性。（M03 / 適用限制；S001, S003）
- 範例：H=350° 時類似色為 320°、350°、20°。
- 視覺：色輪指針與即時色票
- 互動：harmony

## SL08 色彩與心理

- 學習目標：區分情緒聯想與實際情緒改變
- 研究常見黃色與正向高喚起、藍綠與正向低喚起的聯想；多數研究測量聯想而非實際情緒變化。（M04 / 基礎理論；S005）
- 文化、情境、個體及研究方法皆可能影響結果。（M04 / 適用限制；S004, S005）
- 範例：比較黃色與藍綠海報，選擇自己的聯想；不提供心理診斷。
- 視覺：同版面雙色票
- 互動：association

## SL09 眼睛會欺騙你嗎？

- 學習目標：辨識同時對比與解釋限制
- 相同灰色在暗背景旁可能顯得較亮。（M05 / 核心定義；S006）
- 側抑制不足以解釋所有明度錯覺。（M05 / 基礎理論；S006）
- 範例：兩個 #888888 方塊，背景分別 #222222、#EEEEEE；揭曉時統一背景。
- 視覺：遮罩揭曉
- 互動：contrast-illusion

## SL10 60-30-10 配色比例

- 學習目標：將經驗法則用於原創版面練習
- 60-30-10 是室內配色經驗法則。（M06 / 基礎理論；S001）
- 本專案將其延伸為主色、輔助色、強調色的網頁面積示意，不是強制標準。（M06 / 視覺範例；original_example）
- 範例：調整主色與輔色面積，剩餘比例為強調色。
- 視覺：三段色帶與同步版面
- 互動：ratio

## SL11 視覺層級與對比

- 學習目標：使用尺度與對比建立閱讀順序
- 尺度、平衡、對比和知覺組織可協助資訊區分。（M06 / 核心定義；S007）
- 一致色票與適量元素可避免焦點競爭。（M06 / 基礎理論；S007, S008）
- 範例：比較同等大小的標題與內文，以及建立明確大小層級的版本。
- 視覺：原創海報前後對照
- 互動：design-compare

## SL12 好看不等於好讀

- 學習目標：使用 WCAG 文字對比門檻並理解限制
- 一般文字 AA 4.5:1、AAA 7:1；大型文字 AA 3:1、AAA 4.5:1。（M07 / 基礎理論；S009, S010）
- 以線性化 sRGB 相對亮度計算 (較高亮度+0.05)/(較低亮度+0.05)，不能用 HSL 明度取代。（M07 / 基礎理論；S009, S010）
- 4.499:1 不得先四捨五入再判定 4.5:1 合格。（M07 / 視覺範例；S010）
- 單項對比檢查不等於全面無障礙合規。（M07 / 常見錯誤；S009, S010）
- 範例：輸入黑與白，對比為 21:1；相同色碼為 1:1。
- 視覺：文字預覽、比率與文字狀態
- 互動：contrast-check
