## ERR-002 — Windows 跨平台編碼相容性問題

- 發生日期：2026-11-24
- 發生階段：Phase 2 — Source Ingestion
- 發生節點：Source Validation / Unit Testing
- 執行環境：Windows / Python 3.11
- 錯誤類型：UnicodeDecodeError
- 狀態：RESOLVED

### 問題描述

在 Windows 本機執行來源驗證單元測試時，因 Python 使用 CP950 預設編碼讀取 UTF-8 格式的 sources.json，導致六項測試中有五項發生執行錯誤。

### 根本原因

Python 測試腳本未明確指定文字檔案的讀取及寫入編碼，造成不同作業系統之間的相容性問題。

### 修正措施

統一文字編碼規範，避免 Python 依賴作業系統的預設編碼。

### 重新測試結果

- 測試總數：6
- 通過數量：6
- 失敗數量：0
- 執行錯誤：0
- 執行時間：1.513 秒
- 驗證結果：PASS

### Workflow 改善方向

將文字編碼檢查由單元測試階段提前至 Python 程式碼生成及靜態檢查階段，降低跨平台環境差異造成的執行錯誤。
