# CHROMA — 色彩解碼
*The Science and Art of Color*

色彩不只是裝飾，而是一種無聲的語言。

以 LLM Wiki 驅動的初學者色彩教育專案，結合全螢幕逐頁教學、獨立色彩實驗室與可追溯驗證流程。

Phase 1 初始化已建立；待使用者驗收後進入 Phase 2。尚未 Ingest、建立正式 Wiki、開發 HTML 或部署。來源數量 0。
