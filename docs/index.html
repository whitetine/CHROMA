03

How this knowledge was built專案知識與教學成果

CHROMA 是以 LLM Wiki 驅動的色彩教育專案：來源先被取得、檢查與登錄，再整合為八個已驗證知識模組；教材只從 verified Wiki 生成，網站則由腳本把 Wiki 與教材轉成靜態資料。

  1. raw/證據層：10 篇來源的原創摘要、授權與雜湊。
  2. wiki/唯一正式教學知識來源：M01–M08、詞彙表、知識缺口。
  3. content/衍生教材：14 頁簡報、學習目標、互動規格、8 題測驗。
  4. docs/發布成果：本網站（原生 HTML／CSS／JS，無後端）。

「verified」指摘要層語意審查與結構驗證，不代表獨立學術審查。色彩心理學內容只描述聯想研究趨勢；60-30-10 為設計經驗法則；單項對比通過不代表完整 WCAG 合規。
